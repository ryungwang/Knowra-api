# 글·댓글 자동 번역

> 목표: 전 세계 사람이 각자 자기 언어로 쓰고, 남의 언어로 쓴 글을 자기 언어로 읽는다.

## 켜는 법
```
TRANSLATE_PROVIDER=azure
AZURE_TRANSLATOR_KEY=<키>
AZURE_TRANSLATOR_REGION=<리소스 지역, 예: koreacentral>   # 전역(global) 리소스면 비운다
TRANSLATE_MONTHLY_CHAR_LIMIT=1900000                      # 선택. 무료(F0) 200만 자보다 조금 아래
```
Azure 포털 › 「Translator」 리소스 만들기 › 가격 책정 계층 **F0(무료)** › 「키 및 엔드포인트」에서 키·지역.
꺼져 있으면(기본 none) 아무것도 보내지 않고, 화면은 브라우저 번역 단추(Chrome)로 돌아간다.

## 동작
- 로그인한 사람이 글을 열면, 그 사람 화면 언어와 다른 글·댓글을 자동으로 번역해 보여 준다(「원문 보기」로 되돌림).
- **로그인하지 않은 사람**도 글·목록 제목·댓글의 번역을 받는다 — 단 **이미 해 둔 번역만**(로그인한 독자가 먼저 연 글). 없으면 원문 + 브라우저 번역 단추.
  비로그인 요청으로는 업체를 부르지 않으므로 봇·크롤러가 훑어도 한도가 줄지 않는다(`TranslationService.call`).
- 대화(DM·그룹)도 같다 — 남이 보낸 메시지를 내 언어로. 그 방 멤버만 물을 수 있고, 새 메시지가 오면 그것만 묻는다.
  설정 › 테마 › 「다른 언어 글 자동 번역」으로 끌 수 있다(끄면 「번역하기」 단추만). 로그인했으면 계정에 저장돼(V68 `auto_tr_yn`) 다른 기기에서도 같다.
- 목록(피드·커뮤니티·프로필·저장 등) 카드는 **제목만** 번역한다 — 화면에 그려진 카드를 모아 한 번에 묻고(`/api/translate/titles`, 최대 50개),
  제목 앞 번역 표시에 손을 올리면 원문이 보인다. 본문까지 번역해 둔 글은 그 제목을 다시 쓴다. 검색 결과는 찾은 낱말이 보이게 원문 그대로.
- 번역은 (글·댓글, 언어)마다 **한 번만** 하고 `tbl_translation` 에 둔다 — 100명이 열어도 업체 호출은 한 번. 원문을 고치면 다시 한다.
- 확실히 같은 언어(한국어 글·한국어 화면)는 업체에 묻지 않는다. 로마자·한자 글은 업체가 언어를 판별하고, 같으면 「같음」만 기억한다.
- 멘션·링크·코드는 번역하지 않고, 스포일러 표시(`||…||`)는 지킨다(`TranslateMarkup`).
- 볼 수 있는 글·댓글·메시지만 번역한다 — 비공개 커뮤니티·차단·삭제·가린 메시지는 상세·목록과 같은 기준.
- 지운 글·댓글·메시지의 번역본은 매일 지운다.
- **커뮤니티 이름·소개·규칙**도 번역한다(`/api/translate/community`, 기억 종류 `COMM`) — 들어가기 전에 무엇을 하는 곳인지·어떤 규칙에 동의하는지 읽게.
  주 언어가 있으면 그것으로, 여러 언어면 글자로 판별한다. 규칙은 볼 수 있는 사람에게만(비공개는 멤버만). 커뮤니티 머리·소개 탭·가입 창에 쓰고, 「원문 보기」로 되돌린다.
- **탐색·목록 카드의 커뮤니티 이름·소개**(`/api/translate/communityCards`, 기억 종류 `COMMC`, 한 번에 최대 50개) — 들어갈지 고르는 화면이라서.
  규칙은 빼고 이름·소개만 따로 기억한다. 목록 제목처럼 보이는 카드를 모아 한 번에 묻고, 자동 번역이 켜진 경우만. 탐색 검색 결과·커뮤니티 목록·미리보기 창에 쓴다.
- **커뮤니티 위키 페이지**(`/api/translate/wiki`, 기억 종류 `WIKI`) — 제목·본문을 글과 같은 방식(코드 블록·멘션은 그대로)으로. 위키를 읽을 수 있는 사람만.
  페이지 응답의 `lang`(커뮤니티 주 언어나 글자 체계)으로 화면이 물을지 정한다. 「고치기」는 원문을 연다. 목차의 페이지 제목은 아직 원문이다.
- **프로필 자기소개**(`/api/translate/bio`, 기억 종류 `BIO`) — 프로필 응답의 `bioLang` 으로 화면이 물을지 정한다. 내 프로필은 번역하지 않는다.
  소개를 지우거나 탈퇴하면(탈퇴는 소개를 비운다) 다음 정리 때 번역본도 지운다.
- **모임 제목·설명**도 번역한다(`/api/translate/events`, 기억 종류 `EVT`, 한 번에 최대 50개) — 모임 목록과 같은 기준(비공개 커뮤니티는 멤버만).
  모임 응답의 `lang`(글자 체계)으로 화면이 물을지 정하고, 카드마다 「원문 보기」·「번역하기」를 둔다. 설명은 카드를 펼치면 번역본으로 보인다.
- **투표 선택지**는 글과 함께 번역한다(`/api/translate/post` 응답의 `poll`, 기억 종류 `POLLO`) — 글이 번역된 경우만. 「はい」「Yes」처럼
  짧아 글자로 언어를 못 가리므로 하나씩 판별하지 않고 한 번에 보낸다. 글의 「원문 보기」를 누르면 선택지도 원문으로 돌아간다.
- **말머리**(`/api/translate/flairs`, 기억 종류 `FLAIR`, 한 번에 최대 50개) — 글 목록·글 상세·커뮤니티 말머리 줄. 「질문」처럼 짧아
  하나로는 언어를 못 가리므로 커뮤니티 주 언어, 없으면 그 커뮤니티 말머리를 모아 글자로 가린다. 자동 번역이 켜진 경우만, 손을 올리면 원문.
  쓰기·관리 화면은 원문 그대로. 비공개 커뮤니티 말머리는 멤버에게만.
- **운영진 문의**(`/api/translate/modmail`, 기억 종류 `MML` 메시지·`MMS` 제목) — 보낸 사람과 그 커뮤니티 운영진(OWNER·ADMIN)만, 남이 쓴 것만.
  문의 응답의 `lang`·`subjectLang`(글자 체계)으로 화면이 물을지 정한다. 자동 번역이 꺼져 있어도 다른 언어면 「번역하기」 단추를 띄운다
  (운영진과 다른 나라 회원이 주고받는 일이 흔해서). 대화 맨 위 줄 하나로 문의 전체를 번역·원문 사이에서 바꾼다.
- **주간 소식 메일**의 다른 언어 글·모임 제목은 받는 사람 언어로 보낸다(목록 제목·모임 번역과 같은 기억을 쓴다). 번역이 꺼져 있거나 실패하면 원문.

## 다른 언어 글 검색
- 「등산」으로 찾으면 hiking·ハイキング·登山 으로도 찾는다 — 검색어를 사이트의 다른 언어(ko·en·ja·zh-Hans·zh-Hant)로 옮겨, 그중 하나라도 맞는 글을 낸다(글만. 커뮤니티·사람·태그는 원문).
- 옮긴 검색어로 맞은 글은 같은 정도로 맞은 원문 글보다 조금 뒤에 둔다(`SearchService.ALT_WEIGHT`).
- 검색어 번역은 (검색어, 언어)마다 한 번 하고 `tbl_query_translation`(V65)에 30일 둔다. 로그인하지 않은 사람은 기억해 둔 것만 쓰고,
  로그인한 사람도 새로 옮기는 검색어는 시간당 100개까지. 100자가 넘는 검색어는 옮기지 않는다. 번역이 실패해도 검색은 원문으로 된다.
- 화면은 결과 위에 「다른 언어로도 찾았어요: …」를 띄우고, 옮긴 낱말도 칠한다.

## 무료 한도 지키기
- 달마다 보낸 글자 수를 `tbl_translate_usage` 에 센다. 상한에 닿으면 그달은 번역하지 않는다(요금이 나가지 않는다).
- 한 사람이 한도를 다 쓰지 못하게 시간당 글 300번·댓글 300번·대화 600번·운영진 문의 300번·말머리 600번·목록 제목 600번·커뮤니티 300번·커뮤니티 카드 600번·위키 300번·소개 300번·모임 300번 제한(`RateLimitInterceptor`).
- 이달 사용량: `SELECT * FROM knowra_com.tbl_translate_usage;`

## 보내는 것
글 제목·본문, 투표 선택지, 댓글 본문, 대화 메시지, 운영진 문의 제목·내용, 검색어, 커뮤니티 이름·소개·규칙·말머리, 모임 제목·설명, 위키 페이지, 프로필 자기소개의 글자. 누가 썼는지·사진은 보내지 않는다. 처리방침 「5. 누구에게 맡기나요」에 Microsoft Azure 가 적혀 있다.

## 아직 안 하는 것
- 목록 카드의 본문 요약 번역 — 제목만 한다(한도를 아끼려고). 요약은 글을 열면 본문과 함께 번역된다
