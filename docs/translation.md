# 글·댓글 자동 번역

> 목표: 전 세계 사람이 각자 자기 언어로 쓰고, 남의 언어로 쓴 글을 자기 언어로 읽는다.

## 켜는 법
```
TRANSLATE_PROVIDER=azure
AZURE_TRANSLATOR_KEY=<키>
AZURE_TRANSLATOR_REGION=<리소스 지역, 예: koreacentral>   # 전역(global) 리소스면 비운다
TRANSLATE_MONTHLY_CHAR_LIMIT=1900000                      # 선택. 무료(F0) 200만 자보다 조금 아래
```
Azure 포털 › 「Translator」 리소스 만들기 › 가격 책정 계층 **F0(무료)** › 「키 및 엔드포인트」에서 키·지역.
꺼져 있으면(기본 none) 아무것도 보내지 않고, 화면은 브라우저 번역 단추(Chrome)로 돌아간다.

## 동작
- 로그인한 사람이 글을 열면, 그 사람 화면 언어와 다른 글·댓글을 자동으로 번역해 보여 준다(「원문 보기」로 되돌림).
  설정 › 테마 › 「다른 언어 글 자동 번역」으로 끌 수 있다(끄면 「번역하기」 단추만).
- 번역은 (글·댓글, 언어)마다 **한 번만** 하고 `tbl_translation` 에 둔다 — 100명이 열어도 업체 호출은 한 번. 원문을 고치면 다시 한다.
- 확실히 같은 언어(한국어 글·한국어 화면)는 업체에 묻지 않는다. 로마자·한자 글은 업체가 언어를 판별하고, 같으면 「같음」만 기억한다.
- 멘션·링크·코드는 번역하지 않고, 스포일러 표시(`||…||`)는 지킨다(`TranslateMarkup`).
- 볼 수 있는 글·댓글만 번역한다 — 비공개 커뮤니티·차단·삭제는 상세·목록과 같은 기준.
- 지운 글·댓글의 번역본은 매일 지운다.

## 무료 한도 지키기
- 달마다 보낸 글자 수를 `tbl_translate_usage` 에 센다. 상한에 닿으면 그달은 번역하지 않는다(요금이 나가지 않는다).
- 한 사람이 한도를 다 쓰지 못하게 시간당 300번 제한(`RateLimitInterceptor`).
- 이달 사용량: `SELECT * FROM knowra_com.tbl_translate_usage;`

## 보내는 것
글 제목·본문, 댓글 본문의 글자. 누가 썼는지·사진·DM 은 보내지 않는다. 처리방침 「5. 누구에게 맡기나요」에 Microsoft Azure 가 적혀 있다.

## 아직 안 하는 것
- 목록(피드) 카드의 제목 번역 — 글을 열어야 번역한다(한도를 아끼려고)
- 채팅 번역 — 다음 단계
