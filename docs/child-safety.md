# 아동 안전 대응 (운영 절차)

> 아동 성착취물(CSAM)과 아동을 성적으로 다루는 내용은 **예외 없이** 지우고 신고한다(이용약관 4항).
> 이 문서는 코드가 해 주는 것과 **사람이 해야 하는 것**을 나눠 적는다.

## 코드가 하는 것

| 상황 | 동작 | 코드 |
|---|---|---|
| 누군가 「아동 안전」으로 신고 | 신고 **한 건**으로 글·댓글을 바로 가린다(REVIEW), 메시지는 바로 가린다 | `ReportAutoHide.afterReport` |
| 같은 때 | 관리자·검수자 모두(`site_role` ADMIN·MOD)에게 알림·푸시 — 알림 설정과 상관없이 | `NotificationEventListener.wantsPush` |
| 같은 때 | 글쓴이에게는 **알리지 않는다**(증거 인멸·경고가 된다) | `ReportAutoHide` |
| 관리자 신고함 | 아동 안전 신고가 맨 위 | `TblReportRepository.findQueue` |
| 사진 올리기 | 불법 이미지 해시 대조 자리(지금은 **대조하지 않음**) | `ImageScanner`, `NoopImageScanner` |

가린 것은 **지우지 않는다** — 수사기관 신고와 증거 보존을 위해 원본이 남아 있어야 한다.

## 사람이 해야 하는 것

1. **바로 확인한다.** 관리자 콘솔 › 신고 큐 맨 위.
2. **아니면** 「문제없음」으로 기각 → 가림이 풀린다.
3. **맞으면**
   - 글·댓글을 삭제하고(사유 「아동 안전 위반」), 계정을 무기한 정지한다.
   - **원본을 보존한다**(DB 행·파일을 지우지 않는다 — 삭제는 표시만 바뀐다). 화면 캡처를 돌려 보지 않는다.
   - **신고한다.**
     - 한국: 경찰청 사이버수사국(ecrm.police.go.kr), 방송통신심의위원회(1377 / kocsc.or.kr)
     - 미국 사용자·미국 법인이면 NCMEC CyberTipline(report.cybertip.org) — 미국 사업자는 법적 의무(18 U.S.C. 2258A)
     - 그 밖의 나라: INHOPE 회원 핫라인(inhope.org)
   - 수사기관 요청이 오면 보존한 원본과 접속 기록(IP·시각)을 법 절차에 따라 넘긴다.
4. 처리 기록은 관리자 기록(audit log)에 남는다.

| 방법 | 비용·조건 | 붙이는 법 |
|---|---|---|
| Cloudflare CSAM Scanning Tool | 무료, Cloudflare 를 CDN 으로 쓸 때 | 대시보드에서 켠다 — **코드 불필요**, CDN 단에서 막는다 |
